# Barbara E. Jones: research website (draft)

A static site: plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to preview it (it loads d3 and Google Fonts from the web).

Alec Chapman drafted it in November 2026 from public sources: OpenAlex, ORCID, PubMed, NIH RePORTER and University of Utah news posts. It uses the same template as Rich Nelson's site. `my-picks.md` records the options and text edits chosen when this copy was downloaded.

## Files

| File | What it holds |
|---|---|
| `index.html` | Page structure, the six sections and the draft-options panel |
| `site.css` | The three layouts (`html[data-layout]`) and four colors (`html[data-pal]`) |
| `site.js` | Fills the page from `data.js`; runs the draft-options panel and in-place editing |
| `viz.js` | Topic x year paper timeline, topic network, research timeline, searchable paper list |
| `data.js` | Generated by `build-data.py`: profile text, topics, papers, grants, timeline |
| `build-data.py` | Rebuilds `data.js` from `source/barb.json` (`python3 build-data.py`); topic tags come from the keyword rules in `RULES` |
| `source/barb.json` | The raw public data: papers with OpenAlex citation counts, grants, and the works left out (`dropped`) |

## Finishing it

1. Apply the choices in `my-picks.md`: set `data-layout` and `data-pal` on the `<html>` tag in `index.html`. Set the paper map default in `site.js` (`defaults.map`), and delete any sections left out.
2. Put the edited text from `my-picks.md` into `profile` in `build-data.py`, then rerun it.
3. Add what public sources did not give: academic rank, an email address, a Google Scholar link, education, and the Moore Foundation grant's exact title and years.
4. Remove the draft-options panel (`<aside class="picker">` in `index.html`) and the editing code in `site.js` (`EDITABLE` and the draft-options block).
5. Add a headshot in place of the `BJ` placeholder (`.photo` in `index.html`).
6. Check the paper list and topic tags. OpenAlex citation counts run lower than Google Scholar's, and a few papers may be attributed to the wrong B. Jones.

## Publishing on GitHub Pages

1. Create a public repository named `<username>.github.io`, or any other name.
2. Commit these files at the repository root.
3. In the repository's Settings > Pages, choose "Deploy from a branch", `main`, `/ (root)`.

The site appears at `https://<username>.github.io/` (or `/<repo-name>/`) within a minute or two.
